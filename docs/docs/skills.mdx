## Use a skill in chat

Ask in your own words, and the agent picks a matching skill. To choose one yourself, type `/` in the message box and pick it from the list.

A skill's full name is `plugin-name:skill-name`. Two plugins can offer the same skill name, and you can still tell them apart.

## Where skills come from

Every skill belongs to a [plugin](/docs/plugins), and installing a plugin is how skills reach the agent.
